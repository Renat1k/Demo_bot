# Перукарня «Найкраща» — Telegram-бот

Telegram-бот для перукарні в Києві. Інтерфейс бота — українською мовою.
Реалізовано меню, навігацію, онлайн-запис із 5-хвилинним утриманням слота,
SQLite-заявки та підтвердження/відхилення майстром. Оплати ще немає.

## Структура

```text
bot-2/
├── bot.py              # точка входу: Application, polling, запуск health-сервера
├── config.py           # токен, ADMIN_CHAT_ID, PORT, DB_PATH, контактні дані
├── database.py         # SQLite: утримання, заявки, статуси, перевірка слотів
├── texts.py            # українські тексти та підписи кнопок
├── keyboards.py        # inline-клавіатури та callback-константи
├── web.py              # Flask health-сервер для Render
├── handlers/
│   ├── __init__.py     # реєстрація всіх обробників
│   ├── common.py       # /start, /menu, /help, головне меню, error handler
│   ├── user.py         # запис, послуги, мої записи, контакти
│   └── admin.py        # адмін-панель, заявки, дії майстра
├── tests/
│   ├── __init__.py
│   ├── test_booking.py # SQLite: утримання, гонки, істечення, рестарт
│   └── test_handlers.py # навігація, скасування, доступи, повторні дії
├── requirements.txt
├── runtime.txt
├── render.yaml
├── .env.example
├── .gitignore
└── README.md
```

## Локальний запуск

Потрібен Python 3.11+.

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Встановлення залежностей:

```bash
pip install -r requirements.txt
```

Змінні середовища:

```powershell
$env:BOT_TOKEN = "токен_від_BotFather"
$env:ADMIN_CHAT_ID = "ваш_telegram_id"
python bot.py
```

`ADMIN_CHAT_ID` необов'язковий: без нього бот працює, але адмін-панель недоступна.
`PORT` теж необов'язковий; локально health-сервер використовує 10000.
`DB_PATH` необов'язковий; за замовчуванням використовується `bot.db`.
Файл `.env.example` — лише шаблон; бот не завантажує `.env` автоматично, тому
змінні треба задати в терміналі або в налаштуваннях хостингу.

Щоб дізнатися свій `ADMIN_CHAT_ID`, напишіть боту будь-яке повідомлення та відкрийте
`https://api.telegram.org/bot<ТОКЕН>/getUpdates`. Значення `message.from.id` — це ваш ID.

## Тести

Тести не потребують Telegram-токена або встановленого PTB: використовуються
тимчасова SQLite та локальні заглушки Telegram-об'єктів.

```bash
python -m unittest discover -s tests -v
```

## Render

У репозиторії є `render.yaml`. Створіть Blueprint або Web Service вручну.
Якщо в репозиторії є інші проєкти, вкажіть **Root Directory: `bot-2`**.

- Build Command: `pip install -r requirements.txt`
- Start Command: `python bot.py`
- Health Check Path: `/health`
- Environment:
  - `BOT_TOKEN` — токен від BotFather;
  - `ADMIN_CHAT_ID` — ваш Telegram ID;
  - `PYTHON_VERSION=3.11.9` (або інша версія 3.11+).

Flask-сервер працює в окремому daemon-потоці й слухає `0.0.0.0:$PORT`.
Це потрібно, щоб Render бачив відкритий порт. Основний бот працює через
`run_polling(drop_pending_updates=True)`.

SQLite-файл `bot.db` створюється автоматично. На Render файлова система
контейнера тимчасова: для збереження заявок після redeploy потрібен persistent
disk або зовнішня БД (`DB_PATH` можна вказати на persistent disk).

На безкоштовному плані Render сервіс може «засинати» без трафіку. Для постійної
роботи потрібен платний інстанс або зовнішній пінг health-ендпоінта.

## Логіка утримання

- При виборі вільного слоту створюється утримання на 5 хвилин.
- Зайнятий або утримуваний слот не показується іншим клієнтам і не може бути
  зайнятий повторно завдяки SQLite-обмеженню.
- «Скасувати вибір», «Назад» або вихід у головне меню звільняють слот.
- Після закінчення 5 хвилин утримання автоматично вважається простроченим.
- Підтвердження клієнта перетворює утримання на заявку зі статусом
  «Очікує підтвердження майстра».
- Майстер підтверджує запис або відхиляє заявку; після відхилення слот
  звільняється.

## Що замінити перед реальним запуском

Демонстраційні дані зібрані в `config.py`:

- `ADDRESS`, `PHONE`, `PHONE_URI`, `INSTAGRAM_URL`, `WORKING_HOURS`;
- `SERVICES` — перелік послуг і цін;
- `DEMO_DATES`, `DEMO_TIMES` — демонстраційні дати й слоти.

Поточні адреса й телефон позначені як демо. Замініть їх на реальні дані перукарні.
Розклад поки демонстраційний; реальна інтеграція графіка майстра — наступний етап.

## Що реалізовано

- Головне меню: «Записатися», «Послуги та ціни», «Мої записи», «Адреса та контакти».
- Вибір послуги, дати, часу та підтвердження заявки.
- 5-хвилинне утримання слоту в SQLite з перевіркою зайнятості.
- Скасування утримання та автоматичне прострочення.
- Заявки зі статусом «Очікує підтвердження майстра».
- Адмін-панель: «Заявки», «Розклад», «Налаштування».
- Підтвердження/відхилення заявки майстром.
- Навігація «Назад» і «Головне меню».
- Перевірка доступу до адмін-панелі за `ADMIN_CHAT_ID`.
- `/start`, `/menu`, `/help`, `/admin`.
- Health-сервер для Render.
